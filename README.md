## English

A personal portfolio built to showcase my work, technical skills, and growth as a software developer.

I believe good software development starts with understanding the problem, making thoughtful decisions, and building useful, maintainable solutions.

### About the Project

This repository contains the source code for my personal portfolio. It showcases my projects, the technologies I use, and my approach to software development.

### Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS

### Getting Started

Prerequisites: Node.js and npm.

```bash
git clone https://github.com/CarolinaAriza-mind/CarolinaAriza.git
cd CarolinaAriza
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
